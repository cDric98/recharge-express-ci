# Recharge Express CI

Site de l'agent de recharge et de retrait 1xBet par Mobile Money.

- `index.html` : le site (une seule page)
- `robots.txt` et `sitemap.xml` : fichiers pour Google
- `netlify.toml` : réglages d'hébergement Netlify

Chaque modification envoyée sur la branche `main` est publiée automatiquement par Netlify.
